# Architecture Decision Records

ADRs record status, context, decision, alternatives, consequences and revisit triggers.

- ADR-001: modular monolith first.
- ADR-002: local-first SQLite initially.
- ADR-003: database-backed durable tasks initially.
- ADR-004: revision-bound batch approval.
- ADR-005: source adapters with provenance.

New decisions must document why, alternatives, trade-offs and evidence that would trigger reconsideration.
